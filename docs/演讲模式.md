# 演讲模式

点击底部 **P**（或按键盘 P），当前窗口显示幻灯片和逐页文稿，另开观众窗口。共享屏幕时，只共享观众窗口。

- 两个窗口需要在同一浏览器、同一站点打开；翻页会同步。
- 观众窗口不显示文稿和底部导航。
- 如果浏览器没有弹出窗口，可使用主讲人页面顶部的“打开观众窗口”链接，在新窗口打开。
- 视频需要在观众窗口中点击播放；播放进度不做跨窗口同步。
- 点击“退出演讲”或按 Esc，返回普通浏览。

## 本次验证

本地 44 页版本：已检查 1026 × 754 和 1280 × 720 的页面布局；已操作双向翻页并确认讲稿切换、观众端无讲稿。内置浏览器未显示自动弹出的窗口，通过同一会话的观众链接打开后完成同步检查。Apple 与 Rams 的 Bilibili 视频均已实际开始播放。播放器提供自动清晰度，不能保证高清。窄屏尺寸覆盖未生效，未将手机布局记为通过。
