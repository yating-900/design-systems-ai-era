## Design Skills 与视觉案例（2026-11-02 核对）

- [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)：设计指引，先理解对象与受众，再确定视觉方向并自查。
- [Impeccable 官方仓库](https://github.com/pbakaus/impeccable)：包含设计指引、定向操作、本地引擎和可配置 hooks。
- [Neo Mirai 图像到网页案例](https://impeccable.style/cases/neo-mirai/)：[打开可交互网站](https://impeccable.style/neo-mirai/index.html)。
- [Live Mode 官方图解](https://impeccable.style/tutorials/iterate-live/)：选择元素、生成变体、比较并接受。

本讲只研究公开文件与案例，没有安装 Impeccable、下载其引擎或启用 hooks。
